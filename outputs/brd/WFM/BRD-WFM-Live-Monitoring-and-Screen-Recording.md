# I. Business Background

The business requires a centralized screen-monitoring function within the Unified Workspace (UWS) system to improve operational supervision, quality assurance, compliance investigation, and incident handling.

Currently, supervisors may not have sufficient visibility into the activities performed by agents on their computers during working hours or customer calls. This makes it difficult to:

* Investigate operational or compliance incidents.
* Verify the actions performed by an agent during a specific call.
* Support agents when an issue occurs.
* Review agent activities for coaching and quality improvement.
* Maintain reliable evidence associated with an agent, call, or business case.

The proposed solution will introduce two functions in UWS:

1. **Live Monitoring:** Allows authorized users to view an agent's screen in real time.
2. **Recording History:** Allows authorized users to search, play back, and review previously recorded agent screen sessions.

> Live Monitoring means one-way screen viewing only. Remote mouse or keyboard control of the agent's computer is not included in the current scope.

# II. Business Objective

The solution aims to:

* Provide authorized supervisors with real-time visibility into agent screen activities.
* Automatically capture agent screen activities according to configured business rules.
* Allow authorized users to retrieve recordings by agent, date, call, or related business reference.
* Apply role-based access controls to live screens and historical recordings.
* Maintain audit records of viewing, playback, downloading, and administrative activities.
* Reduce reliance on manual screenshots or recordings initiated by agents.

# III. Scope

#### A. Live Monitoring

* Add a Live Monitoring page to UWS.
* Display Agents within the logged-in user's authorized Team or management scope.
* Display each Agent's Online Status, TMS Status, Recording Status, recording duration, and latest update time.
* Allow users to search, filter, sort, and refresh the Agent list.
* Allow authorized users to view an eligible Agent's screen in real time.
* Provide a view-only monitoring session without mouse, keyboard, file, or device control.
* Display relevant connection states, including loading, reconnecting, disconnected, offline, unauthorized, and unavailable.
* Attempt automatic reconnection when a live connection is temporarily interrupted, where technically possible.
* Allow authorized users to view an Agent's live screen while a Scheduled or On Demand recording is in progress for that Agent, without interrupting the recording or creating an additional recording session. **(Added per WFM-533)**

#### B. Recording Configuration

* Add a Recording Configuration page for Managers with the required permission.
* Allow Managers to create and edit scheduled recording configurations.
* Allow Managers to define:

    * Configuration name.
    * ~~Business timezone.~~
    * Enabled or disabled status.
    * One or more recording time slots.
    * Applicable Teams and/or individual Agents.
    
* Automatically identify eligible Agents based on the enabled configuration, recording time, recording scope, Agent Online Status, and screen-capture availability.
* Prevent duplicate simultaneous recordings when an Agent qualifies through multiple configuration conditions.
* Prevent unauthorized users from viewing or managing recording configurations.
* Display Agent information in the TMS format (Username and Full Name) wherever Agents are listed on this screen; the No./STT column is not displayed. **(Updated per WFM-533)**
* Select recording scope using a browse-and-add flow: pick a Team, browse/check its Agents, and add them to a combined Selected Agents list; repeat across Teams to build one combined selection. **(Updated per WFM-533 — replaces the prior side-by-side Teams/Individual Agents checklist; see US-08 for full behavior)**
* Display a summary of the selected recording scope when creating, editing, or viewing a configuration: total selected-Agent count plus a per-Team breakdown (e.g., "5 agents selected — Sales A (1), Sales B (4)"). **(Added per WFM-533)**

#### C. Scheduled Screen Recording

* Automatically start an Agent's screen recording when all configured eligibility conditions are met.
* Automatically stop and finalize the recording when:

    * The configured time slot ends.
    * The configuration is disabled.
    * The Agent is removed from the applicable scope.
    * The Agent or Agent Application becomes unavailable.
    
* Store the recording file and its related metadata in centralized storage.
* Save the completed, interrupted, or failed recording session in **Recording History**.
* Prevent Agents from modifying or deleting stored recordings.
* When a Scheduled recording's configured start time arrives while an On Demand recording is active for the same Agent, automatically stop and finalize the On Demand recording, then start the Scheduled recording; the two sessions are saved as separate Recording History records. **(Added per WFM-533)**
* Compress recording files before writing them to storage; decompress/process the file for playback in the browser. Recording duration and metadata remain unchanged. Applies to all recording types (Scheduled and On Demand). **(Added per WFM-533)**
* Store recordings at a reduced resolution to optimize storage: both 480p and HD are supported target resolutions. Applies to all recording types (Scheduled and On Demand). **(Added per WFM-533)**

#### D. On Demand Screen Recording <sub>(formerly "Manual Screen Recording" — renamed per WFM-533)</sub>

* Allow authorized Supervisors and Managers to manually start and stop an Agent's screen recording from Live Monitoring.
* Enable an On Demand recording only when the Agent is Online, available for screen capture, and has no other active recording session.
* Require confirmation before starting or stopping an On Demand recording.
* Continue recording even if the initiating user refreshes, leaves, or closes the Live Monitoring page.
* Prevent multiple simultaneous recording sessions for the same Agent.
* Limit an On Demand recording to a maximum of 30 minutes; automatically stop, finalize, and save it in Recording History when the limit is reached. **(Added per WFM-533)**
* When a Scheduled recording becomes due for the same Agent while an On Demand recording is active, the On Demand recording is automatically stopped and finalized (see Section III.C). **(Added per WFM-533)**
* Finalize and save the session in Recording History with the Recording Type ~~Manual~~ **On Demand**. **(Renamed per WFM-533)**

### E. Recording History

* Add a **Recording History** page to UWS.
* Allow authorized Supervisors and Managers to access recordings within their permitted Team or management scope.
* Store and display Scheduled and ~~Manual~~ **On Demand** recording sessions, including interrupted or failed sessions. **(Renamed per WFM-533)**
* Allow users to search, filter, sort, and navigate recording records.
* Display recording information, including Recording ID, Recording Type, Agent, Team, Start Time, End Time, Duration, Status, and initiation details.
* Allow authorized users to open and play finalized recordings in the browser.
* Allow only Managers with Recording Download permission to download recording files.
* Apply the approved retention policy to archive or remove expired recordings.
* Update the Recording ID to a shorter, user-friendly format; the ID must remain unique and be displayed consistently in Recording History, recording details, downloads, and audit logs. **(Added per WFM-533)**
* Load and play recordings in segments instead of waiting for the entire file to load; playback can begin once the first segment is available while the remaining segments continue loading in the background. **(Added per WFM-533)**
