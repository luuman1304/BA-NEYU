## Entry Guidance

- One row per distinct update or correction applied to this file.
- **Requested Change**: what was asked, in one line.
- **Source**: the approved CR ticket / BRD delta / stakeholder confirmation that authorized the change.
- **Elements Removed**: any task, role, lane, gateway branch, or end-state removal must have been explicitly confirmed per the SKILL.md Change-Control Rules before this row is recorded.
- **Preserved IDs**: confirms existing element IDs were kept where the element itself was not removed.
- **Validation Result**: the `/camunda-skills:camunda-bpmn` lint result at the time of this change (errors/warnings count).
- Do not delete prior rows when adding a new one — this file is the version history for the diagram in lieu of filename version numbers.
